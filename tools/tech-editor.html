多方块结构 = 需要研究完成后才能搭建或使用的结构（下界门、末地门、凋灵、铁傀儡…）。 游戏里用「大图标 + 右下角小角标」表示：大图标是结构的核心物品，角标是使用它需要的东西（下界门 + 打火石、末地门 + 末影之眼）。
写法：核心id|大图标物品|显示名称|小角标物品，例如 nether_portal|minecraft:obsidian|下界传送门|minecraft:flint_and_steel。 后三段都可以省略，省略时按内置规则自动取图标与角标。
拖拽节点改位置，坐标会自动写回 JSON。
双击画布空白处可重新居中，右键画布打开菜单。
快捷键：Ctrl+Z 撤销、Ctrl+Y 重做、N 新建、Delete 删除选中。
保存需要浏览器支持文件系统访问（Chrome / Edge）；否则用「导出全部」。
